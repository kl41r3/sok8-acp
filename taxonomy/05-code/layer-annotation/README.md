These English reading editions retain the scientific instructions and output contract used for method 2.0.0. Operational paths refer to this release. For a new annotation run, prepare identical source-only packets in fresh independent contexts, collect A/B judgments separately, and give C only complete-label disagreements. Preserve the actual execution configuration and added same-publication evidence.

The released [execution configuration](../../03-screening-review/layer-annotation/execution.json) and saved judgments document the completed study. To reconstruct that study, run the [package command](../README.md); no new model calls are needed. A new model run can produce different scientific judgments.
